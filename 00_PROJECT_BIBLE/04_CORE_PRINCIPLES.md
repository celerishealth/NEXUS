# NEXUS CORE PRINCIPLES

## Principle 0 - Customer Value Before Work

Every proposed NEXUS work item must pass the Top Customer Value Gate:

**"Kya ye paying customer lane ya existing customer ko result dene me help karta hai?"**

YES requires evidence of paying-customer acquisition value or existing-customer result value.

NO, UNKNOWN, unsupported, or guessed value means the work must be rejected or deprioritized.

Customer value never overrides owner approval, safety, tenant isolation, audit, security, privacy, legal/compliance, financial, production, or external-action boundaries.
